A one-line joke about working beside AI coding agents, written by `main.py`
(Python 3.13, standard library only, no network) to `/output/entry.txt`.

> My AI agent found a bug in its own code mid-demo and blamed me — in a comment it wrote itself.

## Run

```sh
python3 main.py
```

The program is deterministic: two runs produce byte-identical output.
